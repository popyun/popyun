# GitHub 项目目录 / Project catalog

这里汇总当前有明确用途的项目，方便从个人主页找到公开作品，也能了解非公开项目的方向和阶段。**“公开范围”说明能否查看仓库；“阶段”说明已做到哪一步，两者并不等同。** 非公开项目只提供经过概括的说明，不提供私有仓库链接、源码、个人资料或内部数据。\
This catalog covers projects with a clear purpose. **Visibility says whether the repository can be viewed; stage says what has been built or validated.** Private projects have high-level descriptions only, without links to their repositories, source code, personal records, or internal data.

阶段按当前仓库文档和已有验证记录描述。MVP 表示核心流程已形成可试用的最小版本，不表示公开上线、生产运行或效果已获目标用户验证。\
Stages reflect current repository documentation and recorded checks. MVP means a minimum usable core flow; it does not imply public deployment, production operation, or validated user outcomes.
